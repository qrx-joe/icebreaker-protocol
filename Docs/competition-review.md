## 三处致命伤

### 🔴 致命伤一：SKILL.md 的价值主张被埋没

**问题：** `SKILL.md` 是整个项目的灵魂——心理学机制清晰、拒绝鸡汤、硬核执行。但评委在 5 分钟内无法从当前文档结构中抓住核心价值。

**具体表现：**
- `SKILL.md` 的 `description` 字段写的是"完美主义者的任务引导协议"，这是一个功能描述，不是价值主张。
- 最有力的一句话——"破冰协议不是又一个时间管理工具"——藏在 `README.md` 的第二段，而不是所有文档的第一句。
- 评委打开项目，第一眼看到的是 `name: icebreaker-protocol`，这是技术标识符，不传递任何价值信息。

**修复方案：**

1. 重写 `SKILL.md` 的 `description` 字段：

```yaml
description: |
  完美主义者的启动引擎。不是"帮你规划"，而是"强制你动手"。
  识别到犹豫信号就立刻介入，把"一直在想但没动"变成"16分钟内产出一个可以改的雏形"。
```

2. 重写 `README.md` 第一句话，使用"场景 + 痛点 + 结果"格式：

> "为'脑子在转、手没在动'的高思考者设计的强制启动引擎——16分钟内把你脑子里的完美计划变成一个可以改的初稿。"

3. 在 `README.md` 中突出"我就是目标用户"的真实性：

> "我作为目标用户：一个脑子里永远在推演、但身体卡在起跑线上的 INTP。"

这句话是极强的说服力武器，不要把它藏在第二段。

### 🔴 致命伤二：Demo 有已知 Bug，核心体验链路断裂

**问题：** 前端在发请求时没有把 `task`、`steps`、`current_step`、`outputs` 完整传回后端，导致 AI 助手在第二步完全失忆。

**具体表现：**
- 用户在第一步确定了选题（例如"程序员防脱发指南"）。
- 进入第二步，点击"需要帮助"，AI 助手只是冷冰冰地复读步骤说明，完全不知道用户刚才选了什么。
- **评委走一遍流程，第一印象直接崩盘。**

**根因定位：**
- 后端 `ChatRequest` 已经包含 `task`、`steps`、`current_step`、`outputs` 字段，接口设计没问题。
- **前端在进入新步骤时，没有将上一步的会话状态作为 Payload 传给后端。** 这是纯粹的前端 Bug。

**修复方案：**

前端每次发送请求时，必须携带完整的 session 状态：

```javascript
const payload = {
  message: userInput,
  history: conversationHistory,
  phase: "step",
  task: sessionState.task,                  // ← 必须传！
  steps: sessionState.steps,                // ← 必须传！
  current_step: sessionState.currentStep,   // ← 必须传！
  outputs: sessionState.outputs             // ← 必须传！
};
```

**额外 Bug：** "继续改进"按钮发送的 `'帮我看看哪里可以改进'` 消息，后端没有针对性处理，会 fall through 到 `server.py:440` 的兜底逻辑，直接返回 `screen: "contract"`——等于把走完全程的用户扔回了签契约页面。

修复方案见 `product-design-decisions.md` 中的 `build_improvement()` 函数实现。

### 🔴 致命伤三：赛道定位模糊，没有对准比赛靶心

**问题：** 比赛有三个赛道——金融、电商、邪修。破冰协议显然走邪修赛道，但当前的定位表述过于宽泛。

**具体表现：**
- "帮完美主义者启动任务"——这个描述太抽象，评委听完不知道你到底做了什么。
- 没有用一个具体的、可感知的场景来锚定产品价值。
- 竞品分析做了（README 里的对比表很好），但没有转化成一句话差异化定位。

**修复方案：**

用"谁 + 场景 + 痛点 + 结果"锐化定位：

> **定位**：为"脑子在转、手没在动"的高思考者设计的强制启动引擎。
>
> **一句话差异**：市面上所有工具都在帮你"管理任务"或"保持专注"，但没有一个解决"从想到做的那一秒"。破冰协议只做这一件事。
>
> **可感知的结果**：16分钟内，从一张白纸到一份可以改的初稿。

**演示策略建议：**
- 不要从功能介绍开始，从痛点场景开始："你有没有这样的经历——脑子里想了一整天，打开文档，光标闪了半小时，一个字没写？"
- 然后 live demo：从"我想写小红书脚本"开始，走完 3-4 步，16 分钟后展示破冰战报。
- 收尾一句话："破冰协议不改造你的性格，只帮你跨过从想到做的那一秒。"
