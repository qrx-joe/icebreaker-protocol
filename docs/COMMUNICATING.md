# 人机协作规范（Human-AI Collaboration Protocol）

> 版本：v0.1 | 创建日期：2026-06-01
> 本文档定义开发者与 AI 助手在迭代破冰协议项目时的沟通规则。

---

## 一、上下文规则

### 1.1 每次对话启动时
- 先提供当前任务的完整上下文（来自 TODO.md 或 NEXT-TODO.md）
- 明确指定要修改的文件路径，不模糊表述

### 1.2 代码修改前
- 要求 AI 先读取相关文件，确认理解后再动手
- 涉及多文件改动时，列出变更清单

---

## 二、需求格式

### 2.1 任务描述标准格式
```
任务：[一句话目标]

验收标准：
- [ ] 标准1（可验证）
- [ ] 标准2（可验证）

相关文件：
- path/to/file1
- path/to/file2
```

### 2.2 禁止项
- 不提"改一下""优化一下"等模糊需求
- 不在同一轮对话中混合多个不相关的任务

---

## 三、代码规范约定

### 3.1 注释要求
- 每个函数必须有 JSDoc / docstring
- 复杂逻辑块前写注释说明"为什么这么做"
- 不注释显而易见的代码（`i++` 不需要注释）

### 3.2 提交规范
- commit message 用中文，格式：`类型(范围): 描述`
- 类型：feat/fix/docs/refactor/test/chore

---

## 四、版本标记

- 本文档更新后同步修改版本号
- 重大规则变更 → 大版本（v0.x → v1.0）
- 补充细化 → 小版本（v0.1 → v0.2）
