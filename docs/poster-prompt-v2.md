# 破冰协议 · 外滩园游会海报 v2 提示词包

> 场景：A4 (210×297mm) 竖版海报，外滩园游会现场张贴，3 秒钩住路人。
> 视觉策略：极简 + 强对比 + 巨大主标题 + 单一视觉焦点 + 唯一 CTA。
> 已砍掉的模块：情绪卡片、底部三栏、说明长条、副标题正文。

## 🇨🇳 中文提示词（适合即梦 / 豆包 / 通义万象 / GLM-Image）

```
一张 A4 竖版海报，尺寸 210×297mm，现代极简主义设计，3 米外能看清，专为街头活动现场张贴设计。

【背景】
柔和的浅色渐变背景：顶部奶油黄 #FFF8E7 渐变到底部天蓝色 #E8F4FF，整体覆盖 2% 透明度的极细网格纹理。不要任何斜条纹、不要重叠的几何色块、不要紫色装饰形状。

【整体布局严格分三个纵向区块】

—— 顶部区（占 30%）：品牌 + 钩子 ——
左上角放置一个小巧 logo 组合：一个被闪电击中的冰块图标（深炭色 + 电光蓝 #2B7FFF），右侧是两行字标，第一行「破冰协议」深炭色加粗，第二行「ICEBREAKER PROTOCOL」浅灰色 #888 大写字母间距宽松。logo 整体高度约 50px。

主标题「破冰协议」四个超大粗体黑字 #0A0A0A，思源黑体 Heavy 字重，占据海报宽度的 60%，位于 logo 下方约 80px 处。「破」字背后有一道暖黄色 #FFD43D 的斜向高光色块，像马克笔划过的痕迹。

主标题下方一行钩子句：「给想法一个强制启动键」深炭色 #333 中等字重约 36pt。其中「强制启动键」五个字下方有一道 4px 的电光蓝 #2B7FFF 下划线，像超链接被点击的效果。

—— 中部区（占 50%）：协议卡片（视觉主体）——
一个干净的 macOS 风格浏览器/应用窗口卡片，水平居中，占海报宽度的 75%，圆角 16px，白色背景，柔和投影。

窗口顶部三个小圆点（红 #FF5F57、黄 #FEBC2E、绿 #28C840），中间一个胶囊形状的 URL 栏写着「icebreaker://protocol」。

卡片内容：
第一行加粗标题：「[Protocol] 已接管任务」深炭色加粗约 28pt，前面有一个绿色脉冲小圆点 #28C840。

下方是 4 个步骤的垂直编号列表，每一步包含：
- 左侧一个大号圆形徽章，电光蓝渐变 #2B7FFF → #1A5FD9，白色数字加粗
- 右侧步骤文字深炭色中等字重约 22pt
- 步骤之间间距 24px

四个步骤文字（逐字使用）：
1. 先写粗糙目标
2. 拆成可交付步骤
3. 限时做出雏形
4. 只改最关键一处

步骤下方一道细横线分隔，下面一行小字浅灰色 #999 约 14pt：「— 3 分钟，把想法变成动手的第一步 —」

—— 底部区（占 20%）：唯一 CTA ——
单行加粗号召语水平居中：
左边一个手指向右的图标 👉，右边文字「拿一个真实任务来试」加粗深炭色 #0A0A0A 约 40pt。其中「真实任务」四个字被一块亮黄绿色 #D4FF3D 的圆角高亮块包裹，像马克笔涂过。

右下角极小字两行签名：第一行「乔瑞雪」深炭色，第二行「Icebreaker Protocol」浅灰色大写间距宽松，约 12pt，低调不抢戏。

【风格基调】
干净、专业、现代的中文产品设计美学，参考 Linear、Notion、Apple 发布会海报的视觉语言应用到中文社群海报上。明亮、抓眼，但克制不杂乱。整张海报视觉焦点必须从 3 米外一眼分清主次：标题 > 协议卡片 > 底部 CTA > 钩子句 > logo。

【严禁出现】
不要底部三张小卡片（启动契约/限时拆解/改进循环）
不要左侧情绪卡片（脑子在转/手却冻住）
不要副标题下的长段正文
不要外滩园游会说明条
不要超过 5 个独立视觉模块
不要任何斜条纹背景、不要紫色装饰块
```

## ⚠️ 给你的最后一句犀利提醒

**AI 生图的中文字几乎一定会有错别字或变形**——尤其是「拆成可交付步骤」「只改最关键一处」这种 6 字以上的长句。

务实做法：让 AI 生成**纯视觉框架**（布局、配色、卡片、装饰），然后你用 Figma / Canva 在导出图上**手动覆盖所有中文文字**。这是国内做海报的标准流程，别指望 AI 一步到位。

如果你坚持 AI 一次成稿，**用通义万象 qwen-image-2.0-pro**——目前中文字渲染最准的国产模型。
