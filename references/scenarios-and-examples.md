# 应用场景详解

以下场景都是核心流程（启动契约 → 任务拆解 → 逐步执行 → 成型 → 改进循环）的具体应用。

## 内容创作

### 小红书脚本

1. 收敛选题：最近有什么经历/发现/观点想分享？→ 给 2-3 个选题建议
2. 拆解：
   - 确定选题 → 产出：一句话说清要写什么
   - 写 3 个备选标题 → 产出：3 个标题（带 hook 感）
   - 写脚本大纲 → 产出：开头 hook + 3-5 个要点 + 结尾 CTA
   - 逐段扩写 → 产出：完整脚本初稿
   - 检查节奏和口语化 → 产出：可发布的终稿

### 博客文章

1. 收敛：你想表达什么核心观点？→ 一句话说清
2. 拆解：
   - 确定核心观点 → 产出：一句话论点
   - 写大纲 → 产出：3-5 个支撑要点
   - 每要点扩展 → 产出：每段核心论点 + 例子
   - 写开头和结尾 → 产出：完整初稿
   - 通读修改 → 产出：可发布的文章

## 编程项目

### Python 爬虫

1. 收敛：你想抓什么数据？从哪个网站？
2. 拆解：
   - 确定目标 URL 和字段 → 产出：数据需求清单
   - 写请求 + 解析代码 → 产出：能跑通的代码
   - 处理翻页 → 产出：完整抓取逻辑
   - 数据存储 → 产出：CSV/JSON 数据文件
   - 测试 → 产出：可运行的完整爬虫

### 个人网站

1. 收敛：网站用来展示什么？给谁看？
2. 拆解：
   - 确定页面结构和内容 → 产出：站点地图 + 每页内容清单
   - HTML 骨架 → 产出：可打开的 HTML 文件
   - CSS 样式 → 产出：有视觉效果的页面
   - 填入真实内容 → 产出：完整网站
   - 测试响应式 → 产出：可部署的网站

## 求职

### 简历

1. 拆解：
   - 列出所有工作经历 → 产出：经历清单
   - 每段经历提炼成果 → 产出：每段 2-3 个量化成果
   - 写技能清单 → 产出：技能分类列表
   - 排版格式化 → 产出：完整简历初稿
   - 检查一致性 → 产出：可投递的简历

### 面试自我介绍

1. 拆解：
   - 列出 3 个核心经历 → 产出：经历清单
   - 每经历写 STAR → 产出：3 个 STAR 故事
   - 串成口述稿 → 产出：1 分钟自我介绍稿
   - 朗读计时修改 → 产出：流畅的口述版本

## 社交破冰

1. 拆解：
   - 确定要联系谁、为什么 → 产出：对象 + 目的
   - 选择消息模板 → 产出：一条完整消息
   - 发送 → 产出：已发送状态

消息模板库：
- 认识同行："hi，看到你在做 XX，我也在做相关方向，方便加个微信交流吗？"
- 请教问题："hi，有个问题想请教，大概占用 3 分钟，现在方便吗？"
- 重新链接："好久不见，刚看到 XX，想起你，最近怎么样？"
- 找工作内推："hi，看到贵司在招 XX 岗位，想了解一下情况，方便聊 5 分钟吗？"

评分标准：**只看你发没发，不看对方回不回**。发出去了 = 任务完成。

## 完整示例

**Example 1：写小红书脚本**
```
用户：我想写一篇小红书笔记但不知道写什么
协议：
1. 展示契约 → 用户确认
2. 收敛选题："你最近有没有什么经历想分享？或者有什么观点想表达？"
   用户："最近在学 Python，踩了很多坑"
3. 拆解：确定选题 → 写标题 → 写大纲 → 扩写 → 检查
4. 第1步："你学 Python 踩的坑里，哪个最想吐槽？用一句话说。"
   用户："装环境搞了一天"
5. 第2步："围绕'装环境搞了一天'写3个标题，要有 hook 感。"
   用户写完 → 第3步...
6. 直到完成完整脚本 → 展示破冰战报

7. 用户点击"继续改进"
8. AI 分析产出，识别最薄弱点："标题缺乏紧迫感，改成更口语化的版本。确认？"
9. 用户确认 → 回到路线图，高亮"写标题"那一步 → 进入编辑
10. 编辑完成 → 回到 Done 页，战报显示"第 1 轮改进"
```

**Example 2：方向迷茫**
```
用户：我想学编程但是不知道做什么项目
协议：
1. 收敛："你有一整天还是只有2小时？" → 2小时
   "想学新东西还是产出成果？" → 产出成果
2. 给3个候选：
   A：用Python写一个自动重命名文件的脚本
   B：用AI辅助做一个待办清单CLI
   C：爬取豆瓣Top250，输出CSV
3. 用户选A → 拆解 → 逐步执行 → 完成可运行的脚本 → 展示破冰战报

4. 用户点击"继续改进"
5. AI 分析产出："脚本能跑但没有错误处理，加一个 try-except 捕获文件不存在的情况。确认？"
6. 用户确认 → 回到路线图高亮对应步骤 → 编辑 → 战报显示第 1 轮改进
```

**Example 3：社交焦虑**
```
用户：我想认识一个同行业的人但不敢开口
协议：
1. 契约 → 确认
2. 拆解：确定联系谁 → 选模板 → 发送
3. 第1步："你想联系谁？做什么的？"
   用户："一个做产品的大V"
4. 第2步："用这个模板：hi，看到你在做XX，方便加微信交流吗？"
5. 第3步："复制发送。评分标准：只看你发没发。"
6. 完成 → 展示破冰战报

注：社交破冰场景通常不需要改进循环——发出去了就是成功。
如果用户想继续，AI 可以建议优化消息模板或拓展联系人列表。
```

## 竞品详细对比

### 传统效率工具

| 工具 | 核心假设 | 做了什么 | 没做什么 |
|-----|---------|---------|---------|
| **Todoist / TickTick** | 你知道要做什么，只是忘了 | 任务管理、提醒 | 不解决"不知道第一步是什么" |
| **番茄工作法** | 你能开始，只是需要专注 | 时间切割 | 不解决"开不了头" |
| **Forest / 专注森林** | 你需要外部约束才能行动 | 游戏化激励 | 不解决"怕做不好所以不动" |
| **GTD** | 任务太多导致焦虑 | 收集、整理、执行系统 | 完美主义者会在整理阶段无限循环 |
| **心理咨询 / CBT** | 核心信念需要长期重构 | 认知行为疗法 | 成本高、周期长、不是即时工具 |
