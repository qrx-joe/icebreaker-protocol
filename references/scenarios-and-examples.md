# 应用场景详解

以下场景都是核心三步（启动契约 → 荒谬拆解 → 思考预算）的具体应用。

## 编程项目（不知道做什么）

1. 收敛：用"方向探索"确定一个项目
2. 拆解：新建文件夹，创建 `main.py`，写一行 `print("hello")`
3. 契约：这个项目的第一版可以只做一件事，也可以有 bug

## 内容创作（不知道写什么）

1. 收敛：从最近的经历中选一件事，任何一件
2. 拆解：打开编辑器，写下这件事的标题（可以是"今天发生的一件事"）
3. 契约：不需要观点深刻，不需要文笔好，只需要"这件事发生了"

## 社交（不敢开口）

1. 拆解：生成一条**复制即用**的消息，不需要用户自己措辞
2. 模板库：
   - 认识同行："hi，看到你在做 XX，我也在做相关方向，方便加个微信交流吗？"
   - 请教问题："hi，有个问题想请教，大概占用 3 分钟，现在方便吗？"
   - 重新链接："好久不见，刚看到 XX，想起你，最近怎么样？"
   - 找工作内推："hi，看到贵司在招 XX 岗位，想了解一下情况，方便聊 5 分钟吗？"
3. 评分标准：**只看你发没发，不看对方回不回**。发出去了 = 任务完成。

## 求职（畏难、自卑、不知道怎么开始）

1. 优势梳理：不要问"你有什么优势"——问"你做过什么具体的事"，然后转化：
   ```
   做过 [具体动作] → 结果是 [可验证产出] → 说明我能 [transferable skill]
   ```
2. 拆解原子步骤：
   - Day 1：打开招聘软件，收藏 1 个岗位，结束
   - Day 2：读该岗位 JD，圈 3 个你符合的关键词，结束
   - Day 3：改简历中一句话，包含这 3 个关键词，结束
   - Day 4：点"投递"，结束

## Examples

**Example 1：完美主义拖延**
```
用户：我想写一篇小红书笔记但总觉得不够好
协议：
1. 展示启动契约 → 用户确认
2. 拆解："打开编辑器，写下标题，标题可以写'还没想好'"
3. 用户犹豫 → 启动30秒思考预算
4. 用户写完标题 → 进入第二步："写正文第一句话"
```

**Example 2：方向迷茫**
```
用户：我想学编程但是不知道做什么项目
协议：
1. 快速收敛：时间？2小时。能量？低。目的？学东西。
2. 生成3候选：
   A：用Python写一个自动重命名文件的脚本（安全）
   B：用AI辅助做一个待办清单CLI（探索）
   C：爬取豆瓣Top250，输出CSV（冒险）
3. 用户不选 → 默认A → 进入拆解
```

**Example 3：社交焦虑**
```
用户：我想认识一个同行业的人但不敢开口
协议：
1. 直接输出模板："hi，看到你在做XX，我也在做相关方向，方便加个微信交流吗？"
2. 评分标准：只看你发没发，不看对方回不回
3. 用户说"发了怕不理我" → "对方不理是对方的操作，你的操作已经完成了"
```

## 竞品详细对比

### 传统效率工具

| 工具 | 核心假设 | 做了什么 | 没做什么 |
|-----|---------|---------|---------|
| **Todoist / TickTick** | 你知道要做什么，只是忘了 | 任务管理、提醒 | 不解决"不知道第一步是什么" |
| **番茄工作法** | 你能开始，只是需要专注 | 时间切割 | 不解决"开不了头" |
| **Forest / 专注森林** | 你需要外部约束才能行动 | 游戏化激励 | 不解决"怕做不好所以不动" |
| **GTD** | 任务太多导致焦虑 | 收集、整理、执行系统 | 完美主义者会在整理阶段无限循环 |
| **心理咨询 / CBT** | 核心信念需要长期重构 | 认知行为疗法 | 成本高、周期长、不是即时工具 |
